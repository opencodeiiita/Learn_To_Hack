Command: find

Description:
The find command is used to search for files and directories based on name, type, size, or permissions.
It is extremely useful in CTFs and system audits to locate sensitive or hidden files.

Useful Flags:

-name
Searches files by name.
Example: find / -name "flag.txt"

-type
Searches by file type (f = file, d = directory).
Example: find . -type f

-size
Searches files by size.
Example: find / -size +100M

-perm
Searches files with specific permissions.
Example: find / -perm 777

-exec
Executes a command on the found files.
Example: find . -type f -exec cat {} \;
